# Circuits 06 — On the Biology of a Large Language Model

**On the Biology of a Large Language Model** and its companion **Circuit Tracing: Revealing Computational Graphs in Language Models** (Lindsey, Ameisen, Pearce, Gurnee, Batson et al., **Anthropic**, March 2025) are the capstone of this series. The methods paper builds a **replacement model** by swapping a model's MLPs for **cross-layer transcoders (CLTs)** — sparse, interpretable features (descendants of the SAEs in Presentations 04–05) that read from one layer but write into all later ones — then derives **attribution graphs** that trace, feature by feature, the actual computation a model runs on a *specific* prompt. **Interventions** validate each edge. Applied to **Claude 3.5 Haiku**, framed as biology under a microscope, the work shows genuine **multi-step reasoning** (Dallas→Texas→Austin, swappable to Sacramento), **forward planning** of rhymes in poems, a **language-agnostic conceptual core**, **addition by parallel heuristics** rather than the algorithm the model claims, **hallucination** as a misfiring known-entity gate over a default refusal, and **unfaithful chain-of-thought**. For engineers it is a mechanistic tool for debugging reasoning, detecting fabricated reasoning, and **AI safety auditing** — with honest limits: only a fraction of computation is captured, attention is invisible, and graphs are partial and labour-intensive.
